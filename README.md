# 🌞 Weather-Monitoring-Dashboard
A dashboard for monitoring weather conditions and predicting weather conditions based on historical data using various machine learning algorithms. The project utilizes a range of models to provide accurate predictions. 

## Tech Stack
[![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![Scikit-learn](https://img.shields.io/badge/Scikit--learn-F7931E?style=flat&logo=scikit-learn&logoColor=white)](https://scikit-learn.org/)
[![Pandas](https://img.shields.io/badge/Pandas-150458?style=flat&logo=pandas&logoColor=white)](https://pandas.pydata.org/)

## Features
* Monitor current weather conditions
* Predict weather conditions using Linear Regression, Random Forest, Decision Tree, Support Vector Machine (SVM), and K-Nearest Neighbors (KNN) algorithms
* Visualize model performance and weather data
* User-friendly GUI for easy interaction

## How to Run Locally
1. Clone the repository: `git clone https://github.com/your-username/Weather-Monitoring-Dashboard.git`
2. Install required libraries: `pip install -r requirements.txt`
3. Run the GUI application: `python gui_rain_predictor.py`
4. Run the main script: `python main.py`
